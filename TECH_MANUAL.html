1. Architectural isolation

The five entry points share a GitHub Pages root and explicit named-arrival protocol. They do NOT share global mutable JavaScript contexts, WebGL resources, browser storage keys or any backend. Legacy Gerudo and Gringotts share immutable engine source files but have distinct HTML launches. The modern Chuzhoy standalone and independent Witch/Elisium renderers are kept intact. A WebGL2 feature test selects older Garden Canvas fallback and a reduced Witch survey in GPU-restricted environments; these do not imply complete native feature parity.

index.html → iframe(worlds/*/index.html)
worlds/chuzhoy/index.html → garden_native.html (6.2.5.1)
worlds/fortress/index.html → shared/legacy/*.js (v3)
worlds/gringotts/index.html → shared/legacy/*.js (data-start-world=gringotts, with optional named tag)
worlds/witchs-hole/index.html → witchs-hole.js (v2)
worlds/elisium/index.html → elisium_native.html (v4.6)

2. Portal protocol

The shared UI uses explicit navigation to named worlds; the native legacy portal onLocal handler was minimally adapted to load sibling world pages. Witch's exit now loads ../chuzhoy/index.html?ws_v=1&ws_entry=chuzhoy-north. Only public arrival names travel. Source world time, saved journal and login state are not transmitted. Custom world mechanisms remain their own authority.

3. Geometry and provenance

H01–H24 proxy GLBs are generated with primitive triangle meshes and guaranteed to be real glTF binaries, not symbolic filenames. All source URLs are candidates from the 24-object curator table, with asset-status set explicitly to placeholder. No original Poly Haven binaries are included. Upstream v0.6 package is known by filename and size but could not be exported from the project Library on this run. Cathedral Rev06 is archived unmodified inside assets/cathedral/ with model and original CAD.

4. Reproducibility and validation

Run node tests/test_unified.mjs and run existing legacy JS tests inside shared/legacy. Run python -m http.server 8000 at repository root and test the Garden, fortress, bank, Witch and Elisium in Chromium. WebGL contexts may be disabled by browser policy; Canvas fallback exists for the relevant engines. Check browser console and navigation behavior before claiming complete GPU validation.

5. Hosted deployment

Upload full repository root to the Webspace repository. GitHub Pages from main/(root). Prefer coherent, atomic commits. Preserve this README and TECH_MANUAL covenant. Avoid checking private keys, customer data, and drafts into a public repo.
