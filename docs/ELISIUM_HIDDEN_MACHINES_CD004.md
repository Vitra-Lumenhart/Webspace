These are original game-fictional sketches, not claims about historical authors.

- NPC movement uses the native \`fastestRoute\` path if available and never starts without a legitimate path. A temporary social scheduling cost fallback is estimated from route edges when the native API does not expose duration; **this fallback is not proof of exact canonical world travel time**. The prototype does not visibly render NPC bodies moving through the 3D scene.
- Distinct interior mechanisms precede interpersonal effects. Coupling presently retains a minimal directed relationship score and public event network, but the full CD-001 S1 relationship-pattern object and emergent S2 institution are NOT claimed implemented. Rumor diffusion, seniority-rich arbitration and LLM-generated discourse remain future extensions.

## Truthful limitations and security
- The integrated panel is an opt-in *candidate* overlay. It can open in the native Elisium wrapper; parent independent sky and existing Kilns remain untouched apart from a new public receipt event.
- The world receives H-IDs and elapsed minutes only. In the event ledger, visibility tags are a *fictional simulation* concept, not a security boundary against someone with local developer tools or raw JSON export. No third-party model/network endpoint receives private user journals.
- The social local clock advances by discretionary social beats and Kilns return duration, while the compressed native parent game owns its own original \`clockMin\`. These two domains are not yet fully reconciled. No character physically enters the Kilns or renders in 3D in this prototype; narrative invitation/arrival uses graph semantics only.
- The panel currently uses prewritten fictional, source-bounded example expressions. User-requested LLM hypothesis/romanticization provider should be added later behind typed validation and an offline fallback. A model should not author raw game-state mutations.
- The social prototype's names and topics should be treated as experimental and replaceable after source audit, not silently promoted to permanent religious character classifications.
