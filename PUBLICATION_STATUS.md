# Publication status · Webspace v4 · 2026-11-09

The main branch now provides a complete self-contained HTML federation of Chuzhoy, Gerudo Fortress, Gringotts, Witch's Hole, and Elisium at `index.html`, including Canvas compatibility fallback.

This GitHub repository does NOT yet contain every editable module, archived CAD asset, or the twenty-four proxy `.glb` files in the complete release ZIP. Obtain those from the Webspace project source package. This status file will be updated when source synchronization is completed.

The Gringotts banking and Proton-service interfaces are art/prototype experiences, not real financial or authentication services.
