# Webspace

Gerudo Fortress, the Garden of Chuzhoy, and Gringotts Gerudo Branch: an interactive WebGL2 world with a Canvas 2D fallback.

Version 3 publication. The complete source and CAD archive is maintained separately. Game UI prototypes do not implement live banking, authentication, secure storage, or Proton service APIs.

## Hosting

Serve the website from the `main` branch repository root using GitHub Pages (Settings → Pages → Deploy from a branch → `main` → `/(root)`).

The full source release is available as `webspace_github_upload.zip` in the corresponding ChatGPT project conversation.
