# The Kilns · child world

An independently navigable **illustrated indoor graph** of the fictional House of Inherited Light within Elisium. Twenty-four instruments (H01–H24) are selectable and record local session observations. This is not yet a 3D furnishing or the full v0.6 Kilns artist package.

`world.json` defines the threshold; object JSON in `objects/` is an editable projection of the asset bank. Runtime data is bundled in index.html for offline operation and must be regenerated or updated when object JSON changes.

Storage: sessionStorage only; optional local JSON export; no server persistence. Child emits `webspace:child-event` to a hosting parent, but the parent-sky game does not yet consume it.

## Art source integration — November 10, 2026

The illustrated room graph now includes an **optional 3D artifact study** for any H01–H24 selection. Clicking **Load current Poly Haven model** calls the official API for the selected donor's current 1k glTF model and all dependency URLs, presenting that current model in a separate orbit/zoom panel. This is live client-side hotlinking, with a visible Poly Haven attribution and no upload, account or API key. Every object also offers **Use Webspace proxy**, which loads the original local H01–H24 GLB without a model download. Both modes leave the private session journal unchanged.

Twenty distinct donors serve the twenty-four slots; their historical art is not a finished fantasy object or a physically furnished 3D interior. Poly Haven's CDN and API must remain available for live mode; the original illustrated game works independently. A validated one-time 1k batch archive is generated by GitHub Actions (20 unique source models mapped to all H objects) and published as an artifact/release outside the Git checkout.

See [LIVE_ART_AND_BATCH.md](../../../assets/kilns/LIVE_ART_AND_BATCH.md) for the loader, provenance, rights, download procedure and caveats. Parent-to-sky gameplay events are still not applied and spatial furniture is still future work.

## Elisium–Kilns Threshold Covenant · proposed Webspace v7

Kilns remains an independent, illustrated indoor child world of Elisium. The child records its original H01–H24 object events in the session-only house journal; this journal is never transferred. Room changes advance the *house* clock by 3 fictional minutes and object examinations by 6. The shared versioned contract at ../threshold.js projects at most 24 unique allowlisted H-IDs, first-observed local minute and elapsed fictional time through same-tab sessionStorage.

Returning to the Elisium parent consumes the handoff once and displays a dismissible/collapsible House echoes interpretation panel. Neither this panel nor the original legacy postMessage changes the independently running native Elisium sky. No names, free-text correspondence, personal information or theological verdicts cross. sessionStorage is not an isolation or authentication boundary; the feature deliberately uses only non-sensitive public identifiers. If storage is disabled, local gameplay remains possible but the handoff is unavailable.

The existing optional Poly Haven source viewer and 24 proxy GLBs are unchanged; furnishings remain unplaced. Test: node worlds/elisium/kilns/tests/test_threshold.mjs and node worlds/elisium/kilns/tests/test_kilns.mjs. A future v2 event receiver must reconcile actual native sky/travel time under a reviewed, game-owned clock interface rather than treating the narrative echo as a sky event.
