Belowroads R0001 — Technical manual

24 November 2026 | single-chamber source prototype | Launch chamber

Changed

Native WebGL2 indexed-by-construction triangle mesh from deterministic cross sections. Coordinates are x across, y up, s distance down passage (z=-s). Continuous analytic floor, centerline, width and roof profiles, nested seeded noise and an inward-facing shell. Side-wall scatter and formations are separate render geometry. The constrained first-person controller shares the same floor and width envelope; it is intentionally conservative and does not provide general triangle-mesh physics or SDF/hex topology. Visual scatter is outside the primary walkable envelope with a small inspectable pedestal.

Rock shader mixes triplanar material sampling, strata, seeded coarse and fine noise, mineral seams, roughness-dependent specular response and normal perturbation. Directional cone and point attenuation model the lantern; entrance daylight decays down the tunnel. No shadow map, global illumination, true volumetric hydrology, or back-half darkness contract yet. The in-world tally is a wall-space shader mask driven by observer angle and range. The sixth stroke uses an allowlisted local phase parameter. True 3D inspection rotates embedded GLB-derived geometry. A fixed 60 Hz movement tick is independent of render cadence. Browser audio uses positional panners and synthesized clips.

Checked

Node parses the exact JS. Native OpenGL ES 3.2 Mesa compiles and links the exact WebGL2 GLSL. Geometry checks exercise seeded parametric mesh generation. Browser navigation/context is blocked in the available Chromium environment; end-to-end input, audio, frame rate, WebGL output and mobile rendering remain unverified. A clear error panel replaces a failed WebGL context, not a 2D drawing.

Deferred

General volumetric SDF, shared hex edge/corner registry, seams, Rapier and BVH, physically valid cliff/ramp contacts, robust mesh raycasts, dynamic remeshing, full accessibility, cross-world portal installation, server security, asset polish, complete five-station route, and actual Pages deployment. This is one isolated proving chamber rather than a full game.

Contract impact

Existing Witch’s Hole and Chuzhoy geometry, private portal boundaries, and prior worlds are untouched. No bank authority or real account data. All intervention parameters are local-only and bounded; no game state beyond the current browser session. A new source revision must preserve this release and append paired documentation.

Rebuild

Place Belowroads_Art_v01 adjacent to the build directory. Run python3 build.py with Python, NumPy, trimesh, Pillow and FFmpeg. The bundled HTML itself has no CDN dependencies. Browser requires WebGL2, DecompressionStream and modern JS. For Linux local serving: python3 -m http.server 8080. Seed 613 is default.

DW-R0002 — The limestone descent

Changed: The 32 m cross-section shell includes an asymmetric dissolution chamber, fracture elbow and blind fissure. Multi-scale roughness, tilted bedding, roof relief and floor undulation drive real geometry. Shell uses 260 longitudinal sections × 112 angular samples, with cached vertex positions/normals; calcite formations and rocks are explicit triangle meshes. A 1024² depth texture and depth-only framebuffer render cave and scatter for the directional lamp. Main pass samples depth with 3×3 PCF and slope-aware bias; separate gravel albedo, higher-resolution 512px original maps, derivative bump, wet/dry masks and absorption replace uniform illumination. Shallow water surfaces have procedural ripple normals and lamp glints, not true reflection or fluid simulation. Daylight approximation fades to zero beyond 11 m, and lamp-off leaves no modeled surface light there. Avatar uses body-height section-derived horizontal bounds and approximate circular formation obstacles; not full mesh contact. Station 1 and inspection remain intact.

Checked: JavaScript syntax, six seed traversal envelopes, approximate 0.2 m walk-grid connection to the end and feasible sixth-mark reveal positions for default phase. Native GLES 3.2 compiles/links both programs and renders four camera views with zero GL errors. R0001 was user-browser verified; R0002 browser navigation/WebGL remains blocked locally. Mobile frame rate, precise collisions and full interaction are not validated.

Deferred: General volumetric hex/SDF terrain, robust BVH/Rapier physics, occlusion-based daylight, realistic water, optimized shadow LOD, external photogrammetry, further stations, portals and persistent systems. Some shadow aliasing remains. No Pages activation inferred.

Contract impact: One safe first-person chamber, no 2D substitute, no permanent consequences or account authority. Original R0001 remains in Git history and local version directory. Existing worlds unchanged.

DW-R0003 — The Bedded Cavern

Changed: Positive-air implicit field combines an elliptical main passage with smoothly joined ellipsoidal side recess, eastern bypass and ceiling dome. Subtract an attached shelf and residual pillar; protected central clearance and a shared floor field preserve the route. Stratigraphy B=y+tilt*x+0.065*s+0.19*sin(0.53*x+0.24*s)+0.11*sin(0.61*s), where s=-z. Hard beds and chert-like seam masks alter geometry and shader materials together. Directional erosion, localized solution bowls, fluting, joints and calcite offsets vary opposite walls. Scalar field sampled on 0.22 m lattice; indexed marching tetrahedra uses a consistent diagonal and edge cache. Field-gradient normals; 32-bit element buffer; depth pass uses same geometry. Controller checks three height rings of eight samples plus inherited scatter circles; this is an approximate clearance test, not continuous swept collision. The floor remains single-valued for this chamber.

Checked: Six seeds reach end and a viewing point for the tally; each reaches the eastern side area (one seed has very limited side clearance). Default mesh 144962 vertices, 289964 triangles, no boundary/non-manifold edges or repeated-index triangles. GLSL linked and four native GLES views rendered without GL errors. Not a browser or mobile playtest. No proof of complete loop navigation or visibility through each line of sight.

Deferred: Full hex graph and general 3D traversal, adaptive/chunk meshing, mesh decimation, worker generation, true swept collision, verified live Vitra geometry changes, photogrammetric assets, POM and improved shadow artifacts. Material variation is procedural, not measured geology.

Contract impact: Preserves original ASCII entry, first-person inspection, Station 1, safe return and no wagers. Source and documentation independently revisioned. No changes to other worlds.
